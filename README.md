# 💈 Barber

Projeto de agendamento para barbearia feito com Next.js.

## Sobre

A ideia do projeto foi criar uma interface simples e bonita para uma barbearia, permitindo visualizar serviços, profissionais e horários disponíveis para agendamento.

O foco foi mais na experiência visual e na organização da aplicação.

## Tecnologias

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- Vercel
